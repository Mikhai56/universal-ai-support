# SupportPilot — Telegram MVP

Telegram-пилот AI-поддержки с базой знаний, историей обращений, безопасной эскалацией и очередью оператора.

## Возможности

- `/start` — начало диалога;
- ответы из `knowledge_base.json`;
- необязательный AI-ответ через OpenAI Responses API;
- автоматическая эскалация платежей, возвратов, privacy, security и юридических вопросов;
- SQLite-история тикетов и сообщений;
- `/operator` — запросить человека;
- `/queue` — очередь эскалаций для администратора;
- `/resolve_ID` — закрыть тикет и уведомить клиента.

## Запуск

1. В Telegram откройте `@BotFather`, выполните `/newbot` и получите токен.
2. Узнайте свой числовой chat ID, например через `@userinfobot`.
3. В терминале задайте переменные:

```bash
export TELEGRAM_BOT_TOKEN='токен_от_BotFather'
export ADMIN_CHAT_ID='ваш_chat_id'
# Необязательно:
export OPENAI_API_KEY='ваш_api_key'
```

4. Запустите:

```bash
python3 bot.py
```

Внешние Python-пакеты не нужны.

## Безопасность

- Не вставляйте токены и API-ключи в исходный код или переписку.
- Не публикуйте файл базы `supportpilot.db`.
- До реального пилота добавьте текст политики конфиденциальности и срок хранения истории.
- Для постоянной работы разверните бота на сервере с TLS, резервным копированием и мониторингом.

## Переход на сайт

Логику базы знаний, эскалации и SQLite можно вынести в HTTP API. Telegram-бот и web-виджет будут использовать один backend и одну очередь операторов.
